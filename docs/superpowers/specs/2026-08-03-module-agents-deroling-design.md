## 1. 背景与量化

spec 2 删了根 `agents/` 并瘦身根 `AGENTS.md`,但**模块级 `AGENTS.md`**(约 19 个)里还残留角色管线术语(软孤儿,非断链)。本次扫除。

逐文件扫描后实际命中很轻:**共 ~26 处**,全是三类:

| 术语 | 出现形式 | 处置 |
|---|---|---|
| `[RD] 全栈工程师` | `主要维护者：[RD] 全栈工程师` / `维护者：[RD] 全栈工程师`(21 处,19 文件) | → `项目开发者`(对齐根 AGENTS.md spec 2 口径) |
| `自愈` | `.kimi`、camera、beauty-engine(3 处) | → `自动修复` |
| `RD 单任务` | camera、beauty-engine(2 处,自愈预算行) | → `单任务` |

> `features/common/chat/AGENTS.md:141` 的命中是**误匹配**——「返回流程」含子串「回流」,属导航功能描述,与角色无关,**不动**。
> 模块 AGENTS.md 里**无** `[CO]/[PM]/[CR]/[QA]/状态板/回流(真)/CO 协调` 等其他管线词——只剩 `[RD]` 与 `自愈`。

## 2. 去角色化规则(机械替换)

1. `[RD] 全栈工程师` → `项目开发者`
2. `自愈` → `自动修复`
3. `RD 单任务` → `单任务`

技术内容(模块职责、约束、实现要点)全部保留——只换角色术语。
