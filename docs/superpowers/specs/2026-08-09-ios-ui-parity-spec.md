## 1. 范围与原则

- **对齐基准**：Android 端现状（参照集）——不是设计稿、不是源码推断
- **一致性分层**（方法论 §0）：结构/布局/功能/文案零容差；图标形状/字体/材质平台免检
- **验收三扇门**：① 主会话（K3）亲自 side-by-side 审查双端截图，② 归一化抽检表全 ✅，③ 用户真机终验。前两门不过不得交付用户
- **反模式**：执行 agent 自报「对齐了」直接信；只编译不看图

## 4. 验收协议（每屏走一遍）

1. 执行 agent 修完后产出 iOS 同状态截图（真机 `idevicescreenshot` 或模拟器）
2. **主会话 K3 亲自 ReadMediaFile 双端并排审**：结构层逐项对 S 表 + 免检项过滤，输出过/不过 + 差异清单
3. 归一化抽检：该屏 S 表数字项全部 ✅
4. 主会话审过 → 装真机 → 用户终验
5. 用户驳回 → 差异回填本 spec（修正标准或再修实现），不许口头修补
