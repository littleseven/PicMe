# polang.net 官网改造设计:产品落地页 + 纳入 git

- **日期**: 2026-07-15
- **状态**: 待评审
- **范围选项**: A(首页重做为产品落地页 + 技术文档降级为页脚链接)

## 1. 背景与问题

- polang.net 现为「技术文档站」:38 个 HTML(01-PRODUCT / 02-ARCHITECTURE / 03-TECHNICAL-SPECS / 04-AGENT-CAPABILITIES / 05-DEVELOPMENT / 06-QA / 07-STANDARDS),首页只顶了个小 hero + 「📚 文档目录」+ 「关于 PoLang」技术段落 → 普通用户看不懂、显粗糙。
- 官网**未纳入 git 仓库**,直接在服务器 `/var/www/picme/docs-site` 上手改文件,无版本管理、无部署流程,各页内联重复同一套 CSS。
- App 已在 Google Play 上架(`com.mamba.picme`),商品信息含丰富用户向内容(7 大功能、隐私强调、免费/无广告、8 张手机截图)。
- 托管在腾讯云**香港**服务器(`43.161.201.142`,区域 `ap-hongkong`),未做 ICP 备案(HK 不在大陆备案强制范围,但腾讯对未备案域名有周期性限制端口/警告的政策风险)。

## 2. 目标

1. 把官网从「技术文档站」转型为「面向用户的**产品落地页**」:少技术细节,多用户可感知的价值,内容取自 Play 商品信息。
2. 把官网静态文件**纳入 git 仓库**版本管理,建立「改 repo → 脚本部署」的开发流程。
3. 维持腾讯云托管(用户决策),接受 HK 未备案现状。

## 3. 非目标(本次不做)

- 跨页抽取共享 CSS(各页内联样式整体重构)—— 延后。
- 多语言(英文版)—— 延后。
- ICP 备案 / 大陆服务器迁移 —— 独立事项,延后。
- Google Play 商品信息改名(觅影-PicMe → PoLang)—— 独立事项,延后。
- 重写 38 个技术文档页内容 —— 原样保留,仅调整入口。

## 4. 关键决策

| 项 | 决策 |
|---|---|
| 托管 | 腾讯云香港盒子(现状,未备案,用户接受) |
| DNS | Cloudflare 权威解析;apex A 记录直指腾讯源站(`43.161.201.142`),「仅 DNS」模式 |
| repo 目录 | 新建顶层 `docs-site/` |
| 部署 | `scripts/deploy-docs-site.sh`(rsync,部署前自动备份 + 校验) |
| 改造范围 | **A**:首页重做为产品落地页 + 技术文档降级为页脚链接 |
| 品牌 | PoLang / 破浪相册 |
| 语言 | 中文 |

## 5. 设计

### 5.1 仓库结构(新增)

```
docs-site/                      # 新增:官网静态站源(镜像服务器 /var/www/picme/docs-site)
├── index.html                  # 重做:产品落地页
├── 00-INDEX.html               # 技术文档索引(保留,页脚「技术文档」指向它)
├── 01-PRODUCT/ … 07-STANDARDS/ # 38 个技术文档页,内容原样保留
├── privacy-policy/             # 隐私政策(Play 过审用),保留
└── assets/
    ├── icon.png                # 应用图标(现有)
    ├── screenshot-*.jpg        # 新增:从 Play 下载的关键截图
    └── qrcode-wechat.jpg       # 现有 winxin.jpg 复用为「扫码下载」
scripts/
└── deploy-docs-site.sh         # 新增:rsync 部署脚本
```

### 5.2 部署脚本(`scripts/deploy-docs-site.sh`)

1. SSH `ubuntu@43.161.201.142`,备份:`cp -r /var/www/picme/docs-site /var/www/picme/docs-site.bak.<timestamp>`。
2. rsync `docs-site/` → `/var/www/picme/docs-site/`(`-avz --delete`,顺带清理服务器上累积的 `index.html.bak.*`;脚本内 `LC_ALL=C` 应对全角标点)。
3. 校验:`curl -s https://polang.net/ | grep '零图片上传隐私安全'`(确认新标语已上线),失败提示用备份回滚。

### 5.3 首页改造(`docs-site/index.html`,从上到下)

1. **顶栏(极简)**:PoLang logo + GitHub 链接(移除原 9 项文档式导航)。
2. **Hero**:PoLang 图标 + 「破浪相册 PoLang」+ 标语「零图片上传隐私安全,用自然语言搜索本地相册、编辑照片。」+ 主 CTA「Google Play 下载」(绿色 Play 按钮,首位最显眼)+ 次 CTA「GitHub」+ 三枚徽章:`免费` `无广告` `本地隐私`。
3. **核心功能**(6 卡片网格,每卡 = 图标 + 标题 + 一句话):
   - 🤖 **对话式 AI 助手** — 用自然语言搜相册、编辑照片(「找去年夏天的照片」「把这张调暖一点」)
   - 🖼️ **智能相册** — AI 自动打标签(场景/人物/物体/活动),自然语言搜索,智能分类
   - ✨ **AI 美颜编辑** — GPU 加速专业美颜(磨皮/美白/瘦脸/大眼/唇色/腮红),一键 AI 优化
   - 🎨 **创意滤镜** — 徕卡(经典/鲜艳/黑白)、胶片(金/富士/复古)、实时 GPU 特效,可批量
   - 📷 **实时美颜相机** — 零延迟快门(<50ms),人脸追踪不脱妆
   - 📱 **飞书远程控制(实验)** — 在 IM 里浏览/搜索/编辑相册
4. **隐私优先**(突出区):端侧 AI、零图片上传、不采集任何数据(取自 Play「数据安全」);三项打勾呈现。
5. **截图**(手机截图轮播/网格):关键截图下载到 `assets/` 本地引用。
6. **下载 CTA(二次)**:Google Play 按钮 + 微信扫码(二维码图)。
7. **页脚**:`© PoLang — 雕刻时光,瞬间永恒。` + 链接:隐私政策 / 技术文档 / GitHub。
- **移除**:首页「📚 文档目录」区、「关于 PoLang」技术段落。

### 5.4 技术文档(38 页)处理

- 内容**原样保留**。
- 从首页**移除直通入口**,改为页脚一个低调「技术文档」链接(→ `00-INDEX.html`)。
- 公开门面 = 产品页;技术文档仍可达,但不再喧宾夺主。

### 5.5 技术方式

- 纯静态 HTML,无构建步骤。
- 首页沿用现有「页内内联 `<style>`」模式(与其它页一致;跨页共享 CSS 抽取延后)。
- 移动端响应式:沿用现有 `@media` 处理,新区块补 mobile 适配。

## 7. 风险与备注

- **备案**:HK 未备案继续用(用户接受)。可选加固(不在本次范围):把 Cloudflare 上 `polang.net` 的 A 记录从「仅 DNS(灰云)」切「代理(橙云)」,源站仍在腾讯、边缘走 CDN、隐藏源 IP。提示用户另议。
- **截图外链**:关键截图下载到 `assets/` 本地引用,避免长期依赖 `play-lh.googleusercontent.com`。
- **品牌不一致**:官网 = PoLang,Play 商品名仍是「觅影相册-PicMe」。下载按钮指向现存 PicMe 商品页(正确,app 在那);Play 改名为独立事项。
