关于 PoLang

PoLang（破浪相册）是一款以隐私优先为设计原则的智能相册应用。采用端侧优先（On-Device First）架构，人脸、OCR、图像分析等敏感处理均在设备本地完成，不上传云端。

以 AI Agent 对话为核心交互——用自然语言管理相册、编辑照片、调用端侧能力；同时是 langchain4android 的参考实现，验证端侧 Agent 框架在真实场景的可行性。
