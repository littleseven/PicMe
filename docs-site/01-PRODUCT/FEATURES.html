PoLang 功能交互规范

本文档定义 PoLang 的用户交互流程与体验规则。
产品目标与核心命题见 ../../PRODUCT.md。

目录

  1. 智能相册与图片编辑（核心产品与默认首页）

  3. Agent 交互

1. 智能相册与图片编辑（核心产品与默认首页）

1.1 产品定位

相册与图片编辑是 PoLang 的核心产品场景与应用默认首页。用户在这里完成照片浏览、搜索、管理、美颜编辑等高频操作。相机作为内容采集入口，照片拍摄后自动进入相册流程。

Agent 介入方式： - 语音/文字命令调节编辑参数（“磨皮再强一点”“帮我调成复古风”） - 自然语言相册搜索（“找出去年夏天的照片”“有哪些合照？”） - 批量处理（“把这些照片都调成冷色调”） - AI 一键优化（“帮我优化这张照片”） - 自然语言相册管理（“把这张照片移到旅游相册”“删除模糊的照片”） - 智能分类查询（“显示所有猫的照片”“按地点分组”）

1.2 相册首页

相册首页是用户打开 PoLang 后的首屏，所有其他能力（相机、聊天、模型中心）从这里进入。

页面布局

┌─────────────────────────────┐
│  顶部栏：搜索框 + AI 助手 + 设置   │
├─────────────────────────────┤
│  分类标签栏（横向滚动）      │
│  [全部][人物][地点][事物]    │
│  [收藏][截图][视频]          │
├─────────────────────────────┤
│                             │
│      媒体网格（瀑布流）       │
│      (多选模式/长按操作)     │
│                             │
│                             │
│                    [语音Agent]│
├─────────────────────────────┤
│  [📷 相机][💬 聊天][🤖 模型]  │
└─────────────────────────────┘

底部导航 - 三个入口均显示图标 + 文字标签，降低首次使用成本 - 相机：内容采集入口 - 聊天：AI 助手二级页 - 模型中心：模型下载/设置入口

分类标签系统 - 自动分类：AI 识别照片内容，生成智能分类标签 - 支持标签类型：人物（人脸聚类）、地点（GPS 聚类）、事物（物体识别）、场景（风景/美食/建筑等） - 混合视图：默认「全部」时间轴，可按标签快速过滤 - 自定义相册：用户创建命名相册，手动添加/移除照片

视图模式 | 模式 | 说明 | |——|——| | 网格视图（默认）| 3 列缩略图，长按进入多选 | | 时间线视图 | 按日期分组，大图预览，左滑查看更多 | | 年视图 | 年度精选回顾，大图 + 日期标注 |

1.3 媒体查看器

交互 - 双指缩放（1x~4x） - 缩放态优先平移，禁用翻页 - 回到 1x 后恢复翻页 - 展开/收起跟随手指轨迹 - 左右滑动切换上一张/下一张

工具栏 - 顶部：关闭 | 编辑(图片) | OCR | AI 编辑 | 信息 | 分享 | 删除 | 收藏 - 视频：播放/暂停 | 进度条 | 音量 | 全屏 - 半透明深色背景，浅色图标

媒体信息浮层 - 点击「信息」按钮弹出 - 显示：拍摄日期、位置（地图缩略图）、分辨率、文件大小、设备型号 - AI 标签：自动识别的场景/物体/人物标签 - EXIF 原始数据（可展开）

1.4 静态图美颜编辑

入口 - 工具栏「编辑」按钮（仅图片） - 长按图片直接进入 - AI 对话触发（“编辑这张照片”） - 从聊天页图片消息点击「编辑」

流程 1. 异步加载原图 + 人脸检测 2. 显示 BeautySelector 面板（同相机） 3. 拖动滑块调节参数，200ms debounce 刷新预览 4. 保存为新文件，不覆盖原图 5. 保存后自动进入对比模式（左右分屏：原图 vs 编辑后）

AI 编辑能力 - AI 一键优化：智能识别场景自动推荐参数（P0，开发中），详见 1.4.1 AI 一键优化 - 精准局部美颜：左眼/右眼/左脸/右脸独立调节（P0，开发中） - 对话式调节：通过聊天指令控制美颜参数（P1，开发中） - 智能消除：圈选物体自动消除，AI 填充（P1，开发中） - 专业调色面板：曲线、HSL、分区调色（P1，规划中） - 构图辅助：自动裁剪推荐（三分法、黄金分割），水平校正（P2，规划中） - AI 增强：去雾、超分辨率、低光增强（P2，规划中）

1.4.1 AI 一键优化

定位：P0 核心能力。通过一键触发，系统自动分析照片场景并应用推荐的美颜、滤镜、调节参数，让用户无需手动调参即可获得更好的照片效果。

技术方案：默认走本地 Fast 路径（ML Kit 图像识别 + 人脸检测 + 本地预设规则）；复杂场景可经用户授权后走远程 Smart 路径（视觉大模型）。详见 docs/03-TECHNICAL-SPECS/AI_OPTIMIZATION.md。

入口

入口 页面 优先级 说明
媒体查看器工具栏 相册首页 → 查看单图 P0 顶部工具栏「AI 优化」按钮，最自然的一键入口
编辑器内按钮 图片编辑页 P0 BeautySelector 面板顶部或工具栏中的「AI 一键优化」按钮
批量操作栏 相册首页多选模式 P1 长按多选后底部操作栏「AI 优化」
AI 对话命令 Chat 二级页 P1 用户发送图片并说”帮我优化这张照片”
IM 远程控制 飞书消息 P2 实验线，与 IM 远程控制同步推进

核心流程

单图一键优化（媒体查看器入口）

用户点击「AI 优化」
    ↓
系统进入分析态（本地路径可省略 loading，直接显示参数卡片）
    ↓
本地分析：人脸检测 + ML Kit 图像标签 + EXIF/亮度统计
    ↓
规则引擎匹配场景 preset
    ↓
弹出推荐卡片：
  ┌─────────────────────────────────────┐
  │  [场景图标]  检测到户外人像           │
  │  已适度磨皮美白，提亮肤色            │
  │                                     │
  │  [应用]        [微调]      [换一换]  │
  └─────────────────────────────────────┘
    ↓
├─ 用户点击「应用」
│   ↓
│  GPU 离屏渲染生成新图
│   ↓
│  保存为新文件（不覆盖原图）
│   ↓
│  自动进入对比模式（左右分屏）
│
├─ 用户点击「微调」
│   ↓
│  进入图片编辑页，参数已预填
│   ↓
│  用户可拖动滑块覆盖任一参数
│   ↓
│  保存为新文件
│
└─ 用户点击「换一换」
    ↓
  若未授权云端：弹出授权说明
    ↓
  调用远程视觉模型重新生成推荐
    ↓
  显示新的推荐卡片

编辑器内一键优化

用户进入编辑页
    ↓
点击「AI 一键优化」
    ↓
系统生成 EditRecipe 并直接应用到预览
    ↓
用户可立即拖动滑块覆盖任一参数
    ↓
保存为新文件

关键体验：编辑器内不弹推荐卡片，直接应用并让用户在预览中感知效果，减少一步确认。

状态与反馈

状态 展示 文案示例
分析中 按钮/卡片内小菊花 “正在分析照片…”
推荐成功 推荐卡片 “检测到户外人像，已适度磨皮美白”
应用成功 Toast + 自动进入对比 “已保存优化后的照片”
授权提示 底部弹窗 “智能推荐需要上传压缩图片到云端模型，仅用于生成参数，不会留存。是否允许？”
无网络 Toast “当前无网络，已应用本地优化”
分析失败 Toast “分析失败，请重试或手动编辑”
处理中 全屏 loading “正在生成优化照片…”

推荐卡片规范

卡片内容： - 场景图标（根据识别结果动态）：🧑 人像 / 🍜 美食 / 🏔️ 风景 / 🌙 夜景 / 📝 文档 / ✨ 通用 - 场景名称：“户外人像” / “美食” / “风景” 等 - 一句话说明：“已适度磨皮美白，提亮肤色” - 三个操作按钮：「应用」「微调」「换一换」

按钮行为： - 应用：直接生成并保存新图，进入对比模式 - 微调：进入编辑器，参数已预填 - 换一换：调用远程 Smart 路径重新推荐（需授权）

批量优化

相册首页 → 长按进入多选 → 选择 N 张照片 → 点击「AI 优化」
    ↓
系统对每张照片分别做本地场景识别
    ↓
按场景分组（人像/风景/美食…）应用组内统一配方
    ↓
后台依次处理，显示进度浮层
    ↓
完成后回到相册，新文件自动高亮

批量优化限制： - 单次最多 50 张 - 仅使用本地 Fast 路径（不使用远程 Smart，避免大量上传） - 处理在后台线程，用户可离开相册 - 完成后通过本地通知或相册内提示告知用户

隐私与授权

  • 本地 Fast 路径：无需任何授权，敏感数据不出设备
  • 远程 Smart 路径：
    • 首次触发时显示授权说明弹窗
    • 设置中提供「允许云端 AI 优化」开关
    • 上传图片压缩至最长边 512px，JPEG 质量 80
    • 云端模型仅用于生成参数，不存储用户图片

对话命令

指令 Agent 响应 执行位置
「帮我优化这张照片」 发送优化后的图片 + 一句话说明 本地/远程生成 → 聊天页返回
「把这张照片修好看点」 同上 同上
「优化后太白了」 进入编辑器或重新推荐低美白参数 同上

编辑历史

  • 支持撤销/重做（最多 20 步）
  • 支持对比原图（长按/按钮）
  • 每次保存保留编辑参数副本，可重新调整（非破坏性编辑）

1.5 智能分类与搜索

智能分类 | 分类维度 | 技术方案 | 说明 | |———-|———-|——| | 人脸聚类 | ML Kit Face Detection | 检测人脸 → 特征向量 → 聚类分组，“人物”标签 | | 地点分组 | GPS 信息聚类 | 按拍摄地点聚合，支持地图视图 | | 场景识别 | ML Kit Image Labeling | 自动标注风景/美食/建筑/动物/文字截图等 | | 日期聚合 | EXIF 日期 | 按年/月/日分层聚合 |

自然语言搜索 - 全能搜索框：位于相册首页顶部，支持混合查询 - 查询示例： - “找出去年夏天的照片” → 时间 + 场景过滤 - “有哪些含食物的照片” → 内容识别过滤 - “我和小明的合照” → 人脸聚类 + 关键词 - “在上海拍的照片” → 地点过滤 - “最近一个月拍的视频” → 类型 + 时间过滤 - 搜索结果显示为可交互媒体网格 - 支持从搜索结果中直接编辑/分享/删除 - 搜索历史保留（本地存储，最多 20 条）

OCR 文字提取 - 触发方式：工具栏「提取文字」按钮 / AI 对话触发（“这张图上的文字是什么？”） - 展示方式：原位浮层（白色卡片 + 黑色遮罩） - Header：标题 + 字数统计 - Content：可滚动文字，支持选中复制 - Footer：复制全部 / 分享按钮 - 识别语言：自动检测（中文/英文为主），支持手动切换

1.6 相册管理

自定义相册 - 创建命名相册（支持封面自定义） - 手动添加/移除照片 - 智能相册：基于规则自动收录（如”最近 30 天拍摄”“收藏的照片”） - 相册排序：支持置顶、拖拽排序

批量操作 - 多选模式（长按进入） - 批量：删除、分享、收藏、移动至相册、应用美颜/滤镜 - 全选/反选 - 选择栏显示选中张数

存储管理 - 显示总照片/视频数、总空间占用 - 显示”最近删除”（30 天内可恢复） - 大文件扫描（> 10MB 文件列表） - 相似照片检测（连拍/重复照片推荐删除），入口位于设置页「相册功能」卡片

1.7 AI 编辑进阶

智能消除 - 圈选/涂抹指定区域 - AI 内容感知填充，消除路人/物体/水印 - 支持矩形圈选和自由涂抹两种模式 - 处理后提供对比视图

专业调色 - 曲线工具：RGB 独立通道曲线 - HSL 工具：色相/饱和度/明度独立调节（红橙黄绿青蓝紫 + 品红） - 分区调色：阴影/中间调/高光独立调节 - 预设保存：保存自定义调色方案为预设

构图辅助 - 自动裁剪推荐（基于三分法、黄金螺旋、对称构图检测） - 水平校正（自动检测地平线倾斜角度） - 透视校正（建筑拍摄畸变纠正）

1.8 视频管理

  • 视频缩略图：自动提取关键帧作为封面
  • 视频播放器：基础播放控制 + 进度条预览
  • 视频信息：时长、分辨率、帧率、编码格式
  • 视频截取：选择时间范围截取片段
  • 视频转 GIF：一键生成 GIF
  • AI 视频摘要：自动识别精彩片段生成短视频（P3，规划中）

2. AI 对话页（二级页）

2.1 页面定位

AI 对话页是从相册首页底部「聊天」Tab 或顶部「AI 助手」图标进入的二级页面，是相册/编辑操作的自然语言加速器，而非应用主入口。

2.2 页面布局

采用全屏对话式设计：

┌─────────────────────────────┐
│  顶部栏：返回 + 设置 + 清空   │
├─────────────────────────────┤
│                             │
│      对话消息列表区域         │
│      (支持文本/图片消息)       │
│                             │
├─────────────────────────────┤
│  [当前模式 ▼]  输入框  [发送] │
│  (显示当前推理模式，可手动覆盖)  │
└─────────────────────────────┘

2.3 模型切换（输入框下拉）

显示内容： - 输入框左侧显示当前推理模式标识，而非直接让用户选择本地/远程 - 点击可展开面板，查看当前模式说明或手动覆盖

模式选项： - 本地模式（Qwen3.5-2B）：绿色圆点标识，端侧推理，无网络依赖，适合隐私偏好或离线场景 - 远程模式（DeepSeek 等）：蓝色圆点标识，云端推理，复杂推理能力强

切换行为： - 点击输入框左侧下拉按钮展开选项 - 切换即时生效，当前对话上下文保留 - 切换时显示 Toast 提示：“已切换至本地模式” / “已切换至远程模式” - 本地模型不可用时（未下载/加载失败），自动禁用该选项并提示

默认策略： - 首次安装：默认远程模式（确保最佳体验） - 用户可在设置中设定「隐私偏好」为本地优先 - 无网络时：自动回退本地模式（如可用）

2.4 对话消息类型

消息类型 发送方 展示样式 支持操作
文本消息 用户/AI 用户右对齐气泡 / AI 左对齐气泡 长按复制
图片消息 用户 缩略图 + 点击放大 长按保存/分享
操作卡片 AI 命令执行状态 / 参数确认 / 图片建议 / 计划预览 点击查看详情、确认/取消/应用

2.5 快捷入口栏

聊天页不提供底部快捷入口栏；相机、相册、编辑等能力统一从相册首页进入。用户完成聊天内触发的编辑/拍照后，返回相册首页而非聊天页。

2.6 对话持久化

  • 所有对话消息自动保存到本地 Room 数据库
  • 支持按会话查看历史（当前仅单会话，后续扩展多会话）
  • 应用重启后自动恢复最近对话
  • 消息上限：单会话 1000 条，自动清理最早消息
  • 支持手动清空对话（顶部栏菜单）

3. Agent 交互

3.1 交互模式

PoLang 提供两种交互模式，用户可自由切换：

模式 入口 适用场景
对话模式 底部输入栏 / 语音按钮 复杂指令、连续调节、探索发现
快捷模式 右侧控制栏（相机/编辑页内） 高频单操作、快速调节

端侧能力边界说明： - 端侧模型（Qwen3.5-2B）胜任：明确单指令（“拍照”“磨皮50”）、简单组合指令（“美白30拍照”）、基础闲聊 - 端侧模型局限：复杂多条件（“3秒后切前置再连拍3张”）、深度上下文推理（“再亮一点”）、开放式深度对话 - 超出端侧能力时：自动降级到远程 LLM（非敏感场景）或规则模板兜底

3.4 语音交互

语音输入模式

模式 触发方式 适用场景 默认状态
Push-to-Talk 按住麦克风按钮说话 精确控制、嘈杂环境 默认开启
WakeWord 自动检测语音活动 免手操作、快速指令 默认关闭，可在设置中开启

语音处理流程

AudioRecorder → VAD 检测 → ASR 识别 → LLM 解析 → 命令执行

关键参数 - VAD 阈值：40dB（平衡灵敏度与误触发） - 最小语音时长：100ms - 最大片段时长：4000ms - 静音超时：800ms

Agent 语音反馈 - 识别成功：「已为你调高美颜强度」 - 识别失败：「抱歉，我没听清，请再说一次」 - 命令执行：「正在切换至前置摄像头」 - 端侧能力不足：「这个指令有点复杂，让我想想…」（自动切换远程推理） - 模式切换：「已切换至本地模型，正在使用 Qwen3.5-2B」

3.5 体验红线

  • 响应延迟：Agent 回复首字 < 500ms（本地 L2）/ < 1.5s（远程 L3/L4）
  • 语音响应：ASR 识别到命令执行 < 1.5s（本地）/ < 3s（远程）
  • 模型切换延迟：本地↔︎远程切换 < 200ms，无卡顿感
  • 反馈完整：每个用户输入必须有可见反馈，包括降级提示
  • 渐进披露：复杂能力通过对话引导发现，不一次性罗列
  • 降级透明：端侧能力不足时，明确告知用户正在切换模式（可选）
  • 对话恢复：应用重启后对话历史恢复 < 500ms

4. 智能相机（辅助入口）

定位变更（ADR-005 决定 4）：相机从核心产品降级为辅助入口，AI 功能优先级降至 P2。相机主要用于内容采集，拍照后自动进入相册编辑流程。

4.1 美颜系统

功能范围 - 面部精修：磨皮、美白、瘦脸、大眼 - 妆容调节：唇色、腮红、眉毛

交互规范 - 入口：右上角控制栏「美颜」按钮 - 面板：半屏高度，底部滑出 - 实时预览：参数调整即时生效，延迟 < 100ms - 对比功能：长按预览区查看原图，松手恢复

美颜总开关 - 默认状态：关闭（进入相机时人脸检测不运行，节省性能） - 开启方式： - 用户点击美颜面板开关 - 调节任意美颜参数时自动开启（resolveNextBeautySettings） - 关闭方式： - 用户手动关闭开关 - 所有美颜参数归零时自动关闭 - 行为差异： - 关闭时：跳过人脸检测，仅支持滤镜/调色/风格特效 - 开启时：启用人脸检测，支持全部功能（含瘦脸/大眼/唇色/腮红）

人脸十字星 - 锁定人脸且设备运动时显示 - 画面稳定后自动淡出 - 避免长期遮挡构图

4.4 技术约束

  • 人脸检测：MediaPipe Face Mesh 468→106（默认），MNN 2D106（备选）。InsightFace ONNX 与 NCNN 路径已完全移除
  • 渲染引擎：自研 OpenGL ES 管线（大美丽）
  • 拍照处理：GPU 离屏渲染，预览/输出一致性

5. IM 远程控制（实验性融合入口 - P2）

定位调整：IM 远程控制从 P0 降级为 P2 实验线，不占用核心产品研发资源。仅在相册/编辑/对话主路径稳定后投入，并设定明确的数据决策点。

5.1 产品定位

IM 远程控制是 PoLang 的实验性融合入口，将智能相册的核心能力（浏览、编辑、搜索、管理）通过 IM 机器人暴露为远程可调用服务。用户无需打开 App，只需在飞书等 IM 中发送消息，即可完成照片处理、相册管理等操作。

设计原则： - 场景互补：IM 适合「即发即走」的轻量操作，App 内提供完整编辑体验 - 结果交付：编辑后的图片直接通过 IM 返回，无需跳转 App - 隐私分级：敏感操作（人脸编辑等）需设备端确认，非敏感操作（裁剪/调色）直接执行 - 异步解耦：大文件处理后台执行，完成后通过 IM 通知 - 数据决策：设定人均每周使用次数等核心指标，不达标则冻结该线

5.2 飞书机器人接入

配置方式 - 用户通过飞书应用目录搜索「PoLang 相册助手」添加机器人 - 或通过自建应用配置 App ID 和 App Secret - 设备绑定：在 App 中获取配对码，在飞书中发送完成绑定 - 支持多设备绑定（手机 A + 平板 B），可通过 IM 指定目标设备

5.4 远程图片接收与处理

图片上传流程 1. 用户在飞书发送图片 → 飞书开放平台接收 2. FeishuChannelHandler 收到事件 → RemoteCommandDispatcher 解析意图 3. 设备端下载图片（经飞书资源 API）→ 执行编辑命令 4. 结果图片直接通过飞书 OAPI 上传并回复到对话

图片处理限制 - 单张图片最大 20MB（超限自动压缩） - 同时处理队列上限 5 张（防止设备过载） - 处理超时 60s（超时返回错误提示） - 隐私保护：图片不经任何第三方服务器中转

5.5 多设备管理

  • 同一飞书账号可绑定多台设备（手机/平板）
  • 发送消息时默认选择「最近活跃设备」
  • 支持@指定设备（如「@我的平板 处理这张照片」）
  • 设备状态：在线/离线/处理中，通过 IM 卡片展示
  • 设备解绑：IM 中操作或 App 设置页

5.6 IM 远程控制体验红线

红线 定义 验证方式
命令响应 IM 消息发出到 Bot 回复 < 3s（含 LLM 推理 + 设备执行） 端到端计时
图片处理 单张编辑 < 5s（1080p 照片） 计时
图片回传 处理完成到 IM 可见 < 2s 计时
鉴权失败 非法请求拒绝 < 500ms 压测

5.7 隐私与安全

  • 端侧推理优先：人脸检测/美颜处理优先设备端执行，飞书仅做消息通道
  • 传输加密：设备 ↔︎ 飞书全程 HTTPS + 飞书平台标准鉴权
  • 数据不留存：图片不经任何第三方服务器中转
  • 操作审计：所有远程命令操作记录本地日志，用户可查看
  • 设备授权：首次绑定需 App 内配对码确认，支持远程解绑
