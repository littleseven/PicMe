实现方案对比

需求已收敛为：混合模式 + 卡片内嵌按钮 + 本地持久化 + 分层响应。下面是三种实现路径。

A

标量反馈权重（推荐）

为每张媒体资产记录 👍/👎 次数；在 MediaSearchEngine 的 mergeAndRank 里把反馈作为附加排序分。

  • 改动最小，直接复用现有搜索 pipeline
  • 可解释性强：人喜欢某张图，同查询下会靠前
  • “更多类似”可复用 refine_media_search 或按标签扩展

适合快速落地、验证用户价值

B

Agent 闭环驱动

新增 like_result / dislike_result / more_like_this 命令，由 Agent 决定何时重排、何时换查询、何时追问。

  • 对话体验最自然，Agent 可解释推荐
  • 未来可扩展为跨场景统一推荐入口
  • 实现复杂，每次反馈可能触发 LLM 调用

适合追求强 Agent 体验，但周期长

C

Embedding 偏好画像

把点赞图片的 MobileCLIP embedding 聚合成用户偏好向量，用向量相似度重新排序未来搜索结果。

  • 最贴合“找感兴趣图片”的语义
  • 可发现风格/构图相似的图片
  • 需要向量存储和相似度计算，工程量大

适合作为标量反馈的后续增强
